# Senior Medication Reminder (SMR)
SMR is a secure web application built for CSCI 4830: Intro to Software Engineering. It reminds users when to take their prescription through both email and text.
It allows the user to track their past prescriptions and add new ones using a dashboard. 
There is also a way to include notifications for caretakers as well.
## Demo
launch templates/index.html
## Key features
- **Text/Email Reminders:** Reminders are sent to your email or phone. 
- **Calendar:** A visual aid to help organize multiple prescriptions to create a steady regimen.
- **Caretaker reminders:** Caretakers can also receive emails and text reminding them of an upcoming pill.
- **User Authentication:** Secure login and registration
- **Pill Creation Form:** The pill regimen creation form is simple and step-by-step.
- **Scalable Text:** Scalable text built for users who have trouble reading small text.

## Tech Stack
- **Frontend** Vanilla JavaScript, HTML5, CSS
- **Backend/Database:** node.js, SQLite, Flask

## Repository Structure
- `static/CSS`: Styles
- `templates`: HTML
- `static/js`: application logic
- `templates/index.html`: Main application entry point.
